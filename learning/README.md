# Learning

Self-contained guides for learning tools and hardware around Wojtek. Nothing
here is part of the robot stack or the training project, and nothing in
`ros/` or `training/` depends on it.

| guide | what it is |
|---|---|
| [so101_lerobot/](so101_lerobot/README.md) | setting up a pair of SO-101 arms with LeLab, the LeRobot web GUI |
| [wojtek_rl_course/](wojtek_rl_course/README.md) | Colab notebook (Polish): training Wojtek's walking policy with RL step by step, ending with a comparison against the policy deployed on the robot |
